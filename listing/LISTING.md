**Description**

```
Smart Brand Stylist builds a brand kit from what you already have, then keeps the
rest of your design in line with it. Works on any Adobe Express plan — no account,
no sign-in, no subscription.

Start from a logo or a website address. Upload a logo and the colors are read on

What you get:

COLORS — A palette pulled from your source, plus a picker and five harmonies

palette onto the page.

FONTS — Heading and body fonts with suggested pairings, applied to selected text

COPY — Headlines, taglines and body copy written to your brand voice, added to
the document in a click.

AUDIT — Scans the page for off-brand colors, shows where each one is used and
which brand color it would become, and fixes them all in one step. A tolerance
slider decides how close counts as close enough. Every change is a normal edit,
so Cmd/Ctrl+Z undoes it.

Copy suggestions and logo font matching are generated by Claude (Anthropic). Nothing
you write or upload is stored — see the privacy policy for exactly what is sent and
what is kept.
```

## Version details > General

**Add-on package** — `dist.zip`, from `npm run package`. Around 68 KB.

**Application requirements** — Adobe Express. No other Adobe app.

**Third-party service requirements** — declare these; both are real and both are reached
from the add-on:

```
The add-on calls a small helper server run by the publisher
(smart-brand-stylist-api.red-surf-5c86.workers.dev, hosted on Cloudflare Workers).

That server does two things:

1. Reads a public website that the user types in, and returns the colors and font
   families found in its stylesheets. No AI and no account are involved.

2. Forwards copy-suggestion and font-matching requests to the Anthropic Claude API
   (api.anthropic.com) and returns the reply. The API key lives on the server and is
   never in the add-on.

No user account is required and nothing is stored. Daily per-caller limits apply.
```

**Generative AI** — answer **yes**. Adobe's rule is that if the add-on uses generative
AI "in any capacity" the answer must be affirmative, and copy suggestions and logo font
matching both go to Claude.

Two further requirements come with that answer, and both are already met:

- The listing must make clear that generative AI is used. The description says so
  outright: "Copy suggestions and logo font matching are generated by Claude
  (Anthropic)."
- An add-on that generates text must remind the user the content may be inaccurate and
  should be reviewed before publishing. The Copy tab carries that line under the
  Suggest copy button, where it is visible whether or not any suggestion has been
  generated yet (`src/ui/components/CopyTab.tsx`).

**Supported UI languages** — English.

Nothing has been published yet, so the notes below still describe a first release. The

## Before the first submission

The publisher profile is step 9 of the submission flow, not a separate form filled in
beforehand: the listing is entered first and the profile is asked for before the final
submit. It is only required once, on the first add-on. It asks for a public name, a
marketing website scoped to the publisher rather than to one add-on
(https://kredznak.github.io/), a description, and a 250 x 250 logo: upload
`publisher-logo-250.png`. If the add-on is to be available in the EU, trader details
(email, telephone, address) are required too; these are skipped for 1.0.

**Notes to reviewer** are in `REVIEWER-NOTES.md`; paste them into the last step of the form.
